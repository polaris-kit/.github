# Polaris Kit
Modern React design system — accessible components, design tokens and theming for consistent product UIs.

**[Documentation](https://main--6a6a03885409ae6257b04aac.chromatic.com)** · **[Source](https://github.com/polaris-kit/polaris-kit)** · **[npm](https://www.npmjs.com/org/polaris-kit)**


## Packages
| Package | Description |
| --- | --- |
| [`@polaris-kit/react`](https://www.npmjs.com/package/@polaris-kit/react) | Composable React components |
| [`@polaris-kit/tokens`](https://www.npmjs.com/package/@polaris-kit/tokens) | Design tokens (color, space, type, motion…) |
| [`@polaris-kit/themes`](https://www.npmjs.com/package/@polaris-kit/themes) | Light/dark themes + CSS variable engine |
